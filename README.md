# maherhasan.com

Personal site for Maher Hasan, served at [maherhasan.com](https://maherhasan.com) via GitHub Pages.

## What's here

A single-page, dependency-free static site:

- `index.html` — the whole page: a short intro, what I'm currently working on (Govia, Semperr), background and interests, and links out (LinkedIn, email, Instagram).
- `styles.css` — supporting styles (the page also carries its own inline styles; Inter is loaded from Google Fonts).
- `CNAME` — custom domain for GitHub Pages.

## Editing

No build step or framework. Edit `index.html`, push to `main`, and GitHub Pages redeploys.
